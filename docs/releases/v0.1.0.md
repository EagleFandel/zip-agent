# ZIP Agent v0.1.0

Release date: 2026-02-15

## Highlights

- ZIP 转 Git 自动化链路可用于 NOMO -> Gitea -> Coolify 部署流程。
- 支持上传 ZIP 后自动创建仓库、初始化 Git、推送代码。
- 支持通过 `project_id` 删除对应仓库。

## Improvements

- `git_url` 返回值优先使用 `GITEA_PUBLIC_URL`，便于外部系统（如 Coolify）直接访问。
- 新增完整开源协作元信息：`LICENSE`、`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md`、`CHANGELOG.md`。
- 新增 Issue/PR 模板，统一社区协作与变更提交流程。
- README 文档升级为中文主 + 英文摘要，并校正与实现一致性。

## Breaking Changes

- None.

## Known Limitations

- 单次 ZIP 上传大小上限：`100MB`。
- 上传会对目标仓库 `main` 执行强制推送（`git push -f`）。
- 目标仓库需可被部署系统访问。
